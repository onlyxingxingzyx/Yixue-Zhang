# Yixue Zhang — Academic Homepage

A responsive static website for GitHub Pages. It can also be opened locally by double-clicking `index.html`.

## Files
- `index.html` — all page content and publication metadata
- `assets/style.css` — layout, responsive styles, and light/dark theme
- `assets/site.js` — theme toggle
- `assets/favicon.svg` — browser tab and header icon
- `assets/profile.jpg` — profile image cropped from the supplied Scholar screenshot
- `assets/coract-teaser.png` — teaser figure cropped from page 2 of the supplied CoRAct manuscript

## Deploy
1. Create a public repository named `NamelessCrew.github.io`.
2. Upload the contents of this folder to the repository root.
3. Open Settings → Pages.
4. Select Deploy from a branch → `main` → `/ (root)`.
5. Save and wait for GitHub Pages to publish.

## Local preview
Double-click `index.html`. Internet access is only needed for the Google Fonts stylesheet and external links; the page itself is static.
